OpenSGolf feature guide

Everything OpenSGolf adds to Sid Meier's SimGolf: what each feature does, whether it is on when you first play, and exactly where to switch it on. The original game is always the default and always one click away.

How to use this guide

With every option at its default, OpenSGolf plays like the 2002 game, apart from its fixes for the original's own bugs. Everything else on this page is something you choose. Most of it lives in one place: Preferences, opened in a game from the dock's System Functions button. Typing any letter while Preferences is open searches every option by name.

Start here: the launcher and presets

The launcher

On Shown at each start. Where: Preferences › More › Launcher..., or the title menu's Launcher... button

A screen before the title menu with five tabs: Game files (your SimGolf files or the free graphics), How to play (the presets below), Features (see below), Display & sound (window or full screen, Classic, Enhanced or HD graphics, text size, sound, language) and News & updates. Untick Show this at start to go straight to the title menu.

Switch features on from the launcher

Always there Where: the launcher's Features tab

Every option on this page's reference in one scrolling list, grouped, each with what it does and its tick. The buttons on the left jump to each group. A click switches it on or off at once. Its Feature guide button opens this page.

Presets: how would you like to play?

Original for a new player. Where: the launcher's How to play tab, the Game box on Select Difficulty, or the first line of Preferences › Game options

Original: every extra off, Classic graphics. Original + helpers (recommended): every helper and look on, nothing that changes play. OpenSGolf: the helpers plus weather that matters, forward and middle tees, a second course, more staff and animals to buy. Custom: your own mix. Presets never touch your pauses, controls or the bug fixes. See which options each preset sets.

Fixes for the original's bugs

On Where: Preferences › More › Fix the original game's bugs

Mends glitches of the 2002 game itself, such as gaps at waterfalls, costs charged twice and the golfer list picking the wrong golfer. Untick it to play the bugs exactly as the original had them.

Search every option

Always there Where: Preferences › More › Search options..., or type a letter in Preferences

One box that finds any option by its words and says where it is. Show only changed lists what differs from the original, and Reset to original... puts it all back.

Bigger courses

Original size. Where: the Course size box on Select Difficulty (the world map for Sandbox Mode)

Start on a Large (74 x 74 tiles), Huge (98 x 98) or Giant (128 x 128) map instead of the original's 50 x 50. The view zooms further out and golfers and staff cover the whole map. Scenarios and championships keep their own size.

Playing on today's devices

Save anywhere, quick save

Always there Keys: Shift+S save, Shift+L load, Shift+F5 quick save, Shift+F9 quick load

Save at any moment, not only between rounds. Quick save writes a quick save slot at once without the Save dialog; quick load brings it back.

Undo

Always there Keys: Ctrl+Z (Cmd+Z on a Mac), or the touch Undo button

Takes back the last click or drag with a building or terrain tool, and its money. Golfers, the clock and money earned since are left as they are.

Faster and slower game speeds

Always there Keys: ] faster, [ slower

Adds x2 and x4 speeds to the original's. Each key stops at the end instead of going round.

Full screen and any window size

Always there Keys: F11 or Alt+Enter; also the launcher's Display & sound tab

Plays in a window of any size or full screen, kept for the next start. In full screen, the pointer at the screen's edge scrolls as in the original (Edge scrolling, on).

Touch controls

Always there On phones and tablets

Tap to click, drag to scroll, hold for a right click, pinch to zoom, twist two fingers to turn the view. To aim your pro or place a building, drag to set the spot, then tap Swing or the tick. On-screen buttons open holes, turn, change speed and undo.

Controllers and the Steam Deck

Always there Windows, macOS, Linux and the browser

Xbox, PlayStation, Switch and Steam Deck controls: the stick moves the pointer, A clicks, B puts the tool away. On the Deck the Linux AppImage starts full screen in Game Mode.

Change any key

Always there Where: Preferences › Controls and keys › Change keys...

Give any action another key. Original controls and Modern controls presets switch between the original's mouse and keys and a modern set (WASD camera, zoom towards the pointer, drag to place, right-drag panning). Every key is listed below.

Modern mouse controls

Off Where: Preferences › Game options › Controls

Zoom towards the pointer, right click puts the tool away, right-drag panning, and aim and swing your pro with the mouse as on a touch screen. Dragging with the middle button always moves the course. Details.

Camera bookmarks

Always there Keys: Ctrl+Shift+F1–F4 keep a view, Shift+F1–F4 go back to it

Four kept views of the course: where you were looking, the zoom and the turn.

Bigger text

Normal Where: Preferences › Text size (each click steps)

Normal, 125% or 150% text in messages, boxes, tooltips, name tags, touch labels and OpenSGolf's own pages; the boxes grow with it and stay on screen.

Translations

Always there Where: Preferences › Game files › Language, or the launcher

The game's own text in any installed translation, with Central European letters drawn in the game's fonts. Longer translations shrink or wrap to fit.

Pause in the background, pause on big news

Off Where: Preferences › Game options › Controls

Stops the game (and its sound) while its window is in the background, and pauses after a VIP visit, a tournament or a land offer so you never miss them.

Pause while you aim

Off Where: Preferences › Game options › Controls › Pause while you aim your pro

The game stands still while your pro waits for your shot, in tournaments too, and goes on as you swing. Reference.

Speed up to x8

Always there Key: ] speeds up, [ slows down

The game speed now goes up to eight times normal, as well as x2 and x4.

Play upright on phones and tablets

Off Where: Preferences › Game options › Looks › Play upright on phones and tablets

A phone or tablet held upright plays on the whole tall screen, with the dock, panels and money at its edges, instead of asking you to turn it sideways. Reference.

Desktop shortcut

Always there Where: the launcher's Display & sound tab, Make a desktop shortcut (computers)

A shortcut that starts straight on the title menu with your display settings, skipping the launcher. From a command line, --play does the same.

Portable mode

Off Where: an empty portable.txt beside the program (computers)

Keeps saves, settings and packs in a save folder beside the program, with your SimGolf folder beside it as SimGolf or game: good for a USB stick.

Building your course

Measuring tape

Always there Key: hold ' and move the pointer

Measures distances on the course in yards.

Rectangles and fills

Always there With a terrain brush: Shift+drag for a rectangle, Alt+click (Option on a Mac) to fill

Paints a whole rectangle, or the whole connected region of one kind of ground, with the cost shown before you let go.

Drag to place

Off Where: Preferences › Game options › Controls, or the Modern controls preset

Drag to lay a row of benches, flower beds, ball washers, willows or bridges, with the row and its cost shown before you let go.

Course editor

Always there Where: the title menu's Course editor... button; Shift+E opens its scenario settings

Build a course free of charge with the game's own tools, import a heightmap picture, choose the land owned at the start, the cash, the difficulty and the goals, and save it as a scenario to play and share.

Name your holes

Always there Where: click the title of an open hole's Hole Stats

Gives a hole a name of your own, kept with the save.

Forward and middle tees

Off (on in the OpenSGolf preset). Where: Preferences › Game options › Gameplay › Multiple tees

Tab with the Tees tool places a forward or middle tee. Less skilled golfers play from the front, strong golfers, pros and tournaments from the back. Reference.

A second course

Off (on in the OpenSGolf preset). Where: Preferences › Game options › Gameplay › Second course

Once your 18 holes are open, a Course A | Course B switch appears over the Build Course panel and you build holes B1 to B18 on the same land, with their own Course Report and Hole Stats. Reference.

Set a hole's par

Off Where: Preferences › Game options › Gameplay › Set par

Minus and plus buttons on Hole Stats set a hole's par from 2 to 6. Reference.

Turning buildings, path styles, lamps, random trees

Off (on in both helper presets). Where: Preferences › Game options › Looks

Tab turns a placed building or the clubhouse; paths in brick, gravel, dark stone or boardwalk, with lamp posts to place; every tree planted takes a random size and species. Looks only: play is unchanged. Details.

Staff areas

Always there Key: Shift+A

Shows every employee's work ring at once, and the fairways and greens no groundskeeper reaches.

Hole flyover and showcase

Flyover Off (Preferences › Game options › Looks); showcase Always there (Shift+O)

The flyover adds a Fly over button to Hole Stats that flies the camera from the tee to the green and back. The showcase flies over the whole course hole by hole with the interface hidden.

New gameplay

All off for a new player, and all in Preferences › Game options, on the Gameplay and Sandbox pages. Each carries a tag saying how much it changes the game. The full list, with what each preset sets, is in the reference.

Weather that matters

Off (on in the OpenSGolf preset) Noticeable

Rain and snow slow the ball and keep some golfers at home; desert heat waves make it run. Pairs well with Enhanced graphics' rain and seasons, which are looks only.

More visitors

Off Noticeable

Touring pros and invented celebrities drop in, pay more, draw crowds and say what they thought. Moddable through data/visitors.toml.

Left-handed golfers

Off Light touch

About one golfer in ten swings left-handed and curves the ball the other way. Your pro can be one too.

More staff, animals to buy

Off (both on in the OpenSGolf preset)

Hire up to 40 employees instead of 20, and buy pairs of the theme's animals from the landmark strip to cheer golfers up.

Hardcore economy

Off Big change

Higher wages, upkeep and land prices, more interest, lower fees, choosier golfers and at most 12 staff.

Keep the land offer

Off Where: the Sandbox page Light touch

Saying No to the County commissioner's land offer keeps his approval, so you can buy land later from Information › Buy land.

Sandbox switches and the calendar

Off Where: the Sandbox page

Unlock every building and landmark, stop new dandelions, freeze golfer happiness, and run the calendar at half or quarter speed or stop it. Details.

Pull down eyesores

Off Where: the Sandbox page Light touch

Right-click (or long-press) a water tower, radio mast or oil pump on your land and pull it down for §10,000, freeing its tiles. Reference.

Move the clubhouse

Off Where: the Sandbox page Light touch

Right-click (or long-press) the clubhouse to pick it up and put it down anywhere on your land, for what a new clubhouse costs. Not during a tournament. Reference.

Cut content

Off Experimental Only with your own SimGolf files

Fourteen landmarks the original shipped but never used join the landmark strip, as decoration only.

Cheats

Hidden Key: Ctrl+Shift+C on the course

Add or take away money, force a VIP visit, buy all the land, and the sandbox switches. A game in which a cheat was used says so on the Load list, and its course record is no shared challenge.

Knowing your club

Helpers that show you more and leave play exactly as it was. All are in Preferences › Game options › Info, off for a new player and on in both helper presets.

People screen, name tags, live scorecards

Keys: Shift+G People, Shift+H name tags

Every golfer and employee in a sortable list with profiles, a name tag under the pointer, and any golfer's round so far on the original's scorecard.

Landing map and comments by hole

Keys: Shift+D landing map, Shift+I comments by hole

Where golfers' shots on each hole end up, with heat maps of where balls land, golfers wait and golfers complain, and each hole's most frequent comments this month, last month and this year.

History graphs, the year in numbers, report tabs

Key: Shift+Y graphs

The club's and each hole's months as line graphs, a page after the End of Year report comparing the year with the last, and tabs over the F1 to F10 reports to flip between them.

Message history and a clickable ticker

Key: Shift+M

Every ticker message kept to read back, and a click on one takes the camera to the golfer or place it is about.

Home-site details

Point at a home site with no tool in hand

Whose it is, what it cost, what it sold for and what it is worth now.

Path help

Key: Shift+V

Marks the paths that reach the clubhouse and the buildings they miss; a Show button finds a closed building.

Height map

Always there Key: Shift+K (with the Landing map on, also in the Information menu)

Tints the land by how high it stands against the usual ground, so you can see slopes, hollows and ridges before you build. View only.

What unlocks it

Off (on in the helper presets). Where: Preferences › Game options › Info

Clicking a building that is still locked says how many holes open it and how many the course has. Reference.

Challenges and the design lab

Off Where: Preferences › Game options › Info › Challenges and the design lab

Information › Challenges offers six aims, from a perfect par 3 and a signature par 5 to a balanced eighteen and a cash turnaround, checked every month. Hole Stats' Mark before keeps a hole's figures to compare with play after you change it. Reference.

Rounds, club records and the course review

Always there Where: a golfer's profile (Rounds); with Comments by hole on, Hole Stats and Information › Course review

A golfer's profile lists their Rounds at your club. Hole Stats shows each hole's best score and its holes in one, and the ticker announces an ace. Course review is one page of what to look at next: buildings off the paths, tees far from a path, tiles no groundskeeper reaches, dull holes and each hole's top complaint.

Saves and sharing

Autosave

Off (on in both helper presets). Where: Preferences › Game options › Saves

Saves every five minutes of play and as the window goes to the background, keeping the last three.

Saves newest first, with backups

Off (on in the helper presets). Where: Preferences › Game options › Saves

Load Previous Game lists saves newest first with how long ago each was made, saving over a game keeps its last three versions as backups, and the title menu's Continue loads your newest save. Reference.

Save pictures

Off (on in both helper presets). Where: Preferences › Game options › Saves

Load Previous Game draws a map of the selected save's course. Double-click (or double-tap) a save to load it.

Course sharing and challenges

Off (on in both helper presets). Where: System Functions › Share course

Copies a course code to send a friend. They press Ctrl+V anywhere in OpenSGolf and your course joins their championship courses, with your course record as the score to beat.

Import and export saved games

Off (on in both helper presets). Where: buttons in Load Previous Game

Move games between the browser, a computer and a phone. A save file is complete on its own and loads on any version.

Bring your old SimGolf saves

Always there Copy .sve files into Saved Games, pick them with Import, or drop them on the window

Saved games of the original come over as new games: course, holes, buildings, money, date, members, people and staff. The original's Top 10 Designers come too.

Graphics

With both Enhanced and HD off you play in Classic, the original's own graphics, pixel for pixel. Both switches are in Preferences › Graphics and on the launcher, and they can be on together. None of them changes how the game plays.

Enhanced graphics

Off Where: Preferences › Graphics › Enhanced graphics; its options under Enhanced graphics settings...

Draws the same art for today's screens: sharp text and art at 4K, the interface at a wide screen's edges, smooth zoom and motion, and over fifty optional effects on five pages (Display, Effects, Atmosphere, Weather, Water): living water with ducks and reeds, shadows, time of day, rain, mist, wind, seasons, late-winter snow, lit windows and more. If the game runs slowly it eases off by itself. Every option.

HD graphics, made from your files

Off Where: Preferences › Graphics › Make HD graphics from my SimGolf files (beta)...

An AI upscaler built into the game redraws your own SimGolf art sharper, on your own device, while you play, then switches HD on. Remove HD graphics... undoes it. Needs your own SimGolf files; not in browsers yet.

Pixel-perfect scaling

Off Where: Preferences › Graphics

Scales the picture by whole numbers only, so every pixel of the art is the same size. Works with Classic too.

Interface at the screen's edges

On Where: Preferences › Game options › Looks

On a wide screen the dock, panels and money sit at the screen's edges instead of in a 4:3 box in the middle, with Classic graphics too.

Photo mode

With Enhanced graphics On Key: C, or the camera button over the course

Hide the interface, frame your course, add a look and a focus blur, and save a picture up to 4K. U hides the interface at any time and Shift+F6 takes a screenshot.

Frame rate cap and V-sync

Uncapped Where: Enhanced graphics settings › Display (they count in Classic too)

Cap the game at 30 to 240 frames a second to save battery, or leave it uncapped.

Mods, packs and scenarios

Content packs and game scripts

Always there Where: Preferences › Game files › Content packs...

Packs change prices, buildings, terrain, golfers, text, art and sounds, add scenarios, and can be downloaded from inside the game. Switch each on or off and set their order. How to make one: MODDING.md.

Your own high-resolution art

Always there Through a content pack

A pack can bring hand-drawn pictures and sprite sheets at 2x or 4x the original's size, drawn sharp at any window size. sgtool hd-kit makes a starter kit and sgtool pack-check checks it.

The free graphics

Always there Used when no SimGolf files are found

OpenSGolf's own art, sounds and text, with nothing from the original, so anyone can play. Your own SimGolf files (a folder, a .zip, the CD or an image of it) can be picked on the launcher at any time.

The browser version

Your files stay on your device

Always there Where: the start page's Choose game folder, or the free graphics

Pick your SimGolf folder, a .zip of it or the CD image: it is read in the browser and never uploaded.

Install it as an app and play offline

Always there Where: your browser's Add to Home Screen or Install

The page installs like an app and, after the first visit, starts with no connection. Only one tab plays at a time, a phone saves files through its share sheet, and the game files can be a .7z as well as a .zip or CD image.

Saves in the browser, and backups

Always there Where: the start page's Saves and packs section

Saved games stay in this browser. Back them up as a .zip and restore them, or move them to the desktop version; screenshots and SimFotos download.

Light and dark pages

Auto Where: the Theme button at the top of these pages

Follows your device's scheme, or stays light or dark.

Help and updates

Updates from inside the game

On check at start. Where: the title menu's Check for updates; Preferences › More

Update now downloads the new version, checks its signature and installs it in place on Windows, macOS, Linux and Android. Only GitHub is contacted, and only then. The browser version is always the newest.

Report a problem

Always there Where: Preferences › More › Report a problem..., or Shift+F8

Opens the bug report form filled in with your version and system, and keeps a copy of your game, a screenshot and an exact replay to attach. Nothing is sent until you submit the form.

What's new

Always there Where: Preferences › More › What's new..., or the launcher's News tab

This version's highlights, with a Try it button for new options, and the full changelog.

Enhanced graphics settings

Preferences › Graphics › Enhanced graphics settings. Every page starts with the master switch, Enhanced graphics (off: Classic), which is off for a new player: with it off you play in Classic and none of these draw, except the three marked as counting with Classic too. The last column is what each option is set to once you switch Enhanced graphics on. Graphics only: play is never changed.
